# GDP-Prediction
O PIB brasileiro é divulgado com meses de atraso. Este projeto estima o crescimento econômico em tempo real com indicadores antecedentes (IBC-Br, produção industrial, PNAD) — abordagem usada por bancos centrais e instituições financeiras. Dados públicos do BCB e IBGE. Implementa ARIMA, SARIMA e VAR com backtesting rolling.
